# 新建任务的常用属性

新表单在对应项目和当前用户范围内沿用上次成功创建时的优先级、标签。只保存这两个字段；标题、描述、状态、经办人、日期、重复规则、关联、分支、会话绑定和执行授权均不写入这份偏好。草稿已有的值优先，编辑旧卡不会更新新建偏好。创建失败或取消表单不更新偏好；偏好存储失败也不会把已创建任务显示为创建失败。

复用现有 taskboardStorage：当前浏览器可用时存本地存储，不可用时沿用服务端存储后备。范围键包含项目ID与当前用户身份。刷新可恢复；不同浏览器或入口之间不承诺自动同步。删除项目标签后，旧偏好中的对应标签不再选中。切换项目加载目标项目偏好；账户变化后需要关闭重开表单再保存，避免旧账户表单写入新账户。

新卡起止日期默认当地今天，两个日期字段直接显示、可以清空或修改。旧卡的空日期和恢复草稿的空日期保留。日期只在点击创建后成为正式任务数据，未保存表单不会生成任务。状态仍由新建入口决定，不从旧偏好或草稿的状态自动改为todo；显式保存后是否进入执行流程由独立项目策略决定。

Git默认值只取当前项目已完成扫描中的本地当前分支：扫描项目身份必须匹配，worktree路径必须唯一精确命中，且对应分支存在于本地分支列表。无Git、detached HEAD、加载失败、身份不匹配时不猜测；手动选择及草稿中的分支优先。扫描不触发checkout或新建worktree。

## 验证与交付边界

组件回归覆盖偏好范围、损坏/写失败、显式保存、项目切换扫描竞态、账户切换、保存失败、草稿优先、手动分支优先及旧卡编辑。隔离Vite页面使用真实TaskEditor和样式，保存只显示fixture JSON，未连接正式任务API；浏览器实际创建fixture结果并刷新后，priority/labels保留而标题为空，日期与分支可见。此证据覆盖表单和浏览器偏好，不能当作正式App重建安装或真实数据库保存验收。

手工复验页面为 test/fixtures/task-editor-defaults.html；只在没有正式API代理的隔离Vite实例运行。fixture需要GET /api/client-storage返回空entries来初始化本地存储，不应使用默认web/vite.config.ts中的正式端口代理。关闭自建Vite进程即可停止；不修改共享Skill、Codex设置或正式任务数据。
