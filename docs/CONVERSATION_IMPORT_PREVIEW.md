# 本地会话导入候选

## 会话选源、可编辑提案及明确保存（Issue #33，2026-10-02）

当前候选已经接通本地 prepare/save/discard API 与项目页界面。先预览元数据，再明确选择一个来源读取用户原文；用户可以修改标题和说明，只有点击保存才原子创建 Backlog 卡与独立来源证据。此流程不调用模型、不推断完成状态、不自动执行。新卡 threadId、legacyThreadId 和执行绑定为空；同来源重复保存返回原卡，重试不覆盖原内容。

服务端要求项目已保存有效的绝对 workspacePath，精确匹配来源目录；本机设备目录映射不自动代替这个配置。缺少目录时先明确配置项目，不能猜测路径。活动来源默认启用，归档需要勾选后再次点击预览。来源根由服务端确定，客户端只提交已预览的来源身份。

提案仅留有界用户文本和证据，最多八个待处理或已保存回执，五分钟有效；过期在后续操作时清理，不建立后台定时器。保存前重新核对项目、来源身份和全文摘要。断开、取消、清除或来源变化阻止后续写入；入口沿用本地来源与实例访问限制；提案按调用方声明的 actor type/id 分组，actor 标识不作为用户认证或凭据。部分覆盖或没有用户文本时禁止保存。单文件最多 2MiB，提取文本最多 32KiB，来源卡暂不支持跨项目移动；归档保留去重，永久删除后可重新导入。

最终新增保存取消与跨平台 fixture 修正后的全 Node 671 项：670 通过、1 项既有条件跳过、0 失败；组件 66/66、typecheck、build:web 通过。HTTP 三项覆盖明确保存、重复回执、身份/来源拒绝；管理器与提取器 41 项覆盖取消、过期、来源变化等情形。独立源码/API/UI 审核 Critical 0 / Important 0。prepare POST 增量四项使用合成文件的真实读取等待 gate，覆盖并发 busy、客户端断开、服务关闭及真实五秒信号；关闭后独立 SQLite 均为零卡，联合相关 HTTP 12/12。此为受控故障注入，不能作为真实慢盘或生产时延证据；新增 save POST 在来源读取期间断连回归：取消后独立库零卡，同 token 明确重试仅创建一张 Backlog 空绑定卡，再次重试返回原回执。save POST 的服务关闭及超时仍由管理器回归覆盖，未对该路径单独注入；文件置换动态覆盖仍有缺口。

隔离 Mac 浏览器使用合成来源与临时数据库，实际完成活动与归档选源、编辑、保存两张卡、重复导入返回原卡、部分覆盖禁止保存、刷新及同库重启。CLI 读到同样两张 Backlog 卡及空执行绑定；来源证据两条。停止自己的两个服务退出 0，关闭两个验收标签页；备份与隔离恢复的任务和来源摘要一致、integrity_check=ok。假 Codex 程序的模型目录探测失败符合隔离配置，没有真实模型调用。

正式 App 尚未包含此候选，未读取个人会话正文或导入正式卡。正式安装会增加 conversation_import_sources 表，更新前须完整备份，回滚须配对恢复 App 与数据快照。Issue #33 在 CI、安装与最终验收完成前保持开放。

# 本地会话来源预览

当前实现是 Issue #33 的来源枚举阶段。项目页顶部的“预览本项目会话来源”读取当前用户 Codex 所选 `sessions`/`archived_sessions` 中 JSONL 的 `session_meta` 首行，按保存的项目目录精确匹配；不解析会话正文来推断任务标题或完成状态。读取以有界块进行，首行后的少量字节可能被读入后丢弃。任务内容整理、可编辑提案及明确保存尚未实现，不能称为完整历史任务导入。

预览显示会话 ID、匹配目录、活动/归档范围、来源相对路径、首行 SHA256 和已有来源卡片 ID。状态与执行绑定保持未知/空值；来源证据不证明当前会话可执行或授权派发。同 ID 同目录合并证据，跨目录冲突涉及当前项目时列为歧义；完全无关项目的冲突 ID 不返回。

点击才请求本地 `GET /api/local/conversation-import-preview?projectId=…`。读取目录由服务端确定，客户端不能提供文件路径；可选 `includeArchived=true/false`，其他值拒绝。归档默认不读，勾选后须再次点击预览；默认根为 `CODEX_HOME/sessions` 或当前用户 `~/.codex/sessions`，归档默认根为相同 Codex home 下 `archived_sessions`；程序调用可以显式配置 `conversationSessionsRoot` 与 `conversationArchivedSessionsRoot`。预览不会保存卡片、调用模型或启动执行。原空项目 AI 按钮改名为“准备 AI 整理请求”，仍只预填草稿；不要将点击当成导入结果。

活动与归档合计最多检查 10,000 个目录项，每文件首行上限 16 KiB。读取失败、链接、坏元数据或超限时显示覆盖缺口；`complete` 仅针对所选来源范围，不代表全部历史。根目录及已开文件核对类型与身份，变动时拒绝。归档根无法读取时显示缺口，保留活动来源；同 ID 在两个根有目录冲突时排除，根身份最终复核失败不保留该根证据。服务同一时间仅处理一个预览；5 秒信号、连接关闭和服务退出会合作式取消，单次文件系统调用的退出时间仍受操作系统影响。

来源回归15项、HTTP生命周期4项、组件4项。现有回归：精确目录、重复来源、相关/无关冲突、链接/坏文件、上限、已有卡提示、HTTP 路径/来源拒绝及零卡片写入；组件覆盖未知状态/证据、失败覆盖提示和关闭后的迟到响应。初版 5 项及当时的 HTTP/组件分别先失败后实现；归档 7 项回归也先失败再修复，本轮 HTTP 生命周期与归档组件为实现后补测。后续安全修正的覆盖按实际证据记录。

独立静态审核与既有测试通过。新增真实合成 HTTP 已覆盖并发忙、活动请求断开后释放、显式归档与缺根提示、服务退出在途取消；根目录身份变动与超时的动态覆盖仍待；未声称完整抵抗同用户恶意持续文件置换。隔离浏览器使用合成元数据与临时数据库，实际预览/证据展开/关闭，卡片数保持 0。正式个人来源、真实安装和最终保存流程另行验收，Issue #33 保持开放。
