# 本地会话来源预览

当前实现是 Issue #33 的来源枚举阶段。项目页顶部的“预览本项目会话来源”读取当前用户 Codex 活动 `sessions` 中 JSONL 的 `session_meta` 首行，按保存的项目目录精确匹配；不解析会话正文来推断任务标题或完成状态。读取以有界块进行，首行后的少量字节可能被读入后丢弃。归档来源、任务内容整理、可编辑提案及明确保存尚未实现，不能称为完整历史任务导入。

预览显示会话 ID、匹配目录、来源相对路径、首行 SHA256 和已有来源卡片 ID。状态与执行绑定保持未知/空值；来源证据不证明当前会话可执行或授权派发。同 ID 同目录合并证据，跨目录冲突涉及当前项目时列为歧义；完全无关项目的冲突 ID 不返回。

点击才请求本地 `GET /api/local/conversation-import-preview?projectId=…`。读取目录由服务端确定，客户端不能提供文件路径；默认根为 `CODEX_HOME/sessions` 或当前用户 `~/.codex/sessions`，程序调用可以显式配置 `conversationSessionsRoot`。预览不会保存卡片、调用模型或启动执行。原空项目 AI 按钮改名为“准备 AI 整理请求”，仍只预填草稿；不要将点击当成导入结果。

最多检查 10,000 个目录项，每文件首行上限 16 KiB。读取失败、链接、坏元数据或超限时显示覆盖缺口；`complete` 仅针对所选活动来源范围，不代表全部历史。根目录及已开文件核对类型与身份，变动时拒绝。服务同一时间仅处理一个预览；5 秒信号、连接关闭和服务退出会合作式取消，单次文件系统调用的退出时间仍受操作系统影响。

现有回归：精确目录、重复来源、相关/无关冲突、链接/坏文件、上限、已有卡提示、HTTP 路径/来源拒绝及零卡片写入；组件覆盖未知状态/证据、失败覆盖提示和关闭后的迟到响应。初次 5 项及 HTTP/组件分别先失败后实现；后续安全修正的覆盖按实际证据记录。

独立静态审核与既有测试通过。根目录身份变动、扫描中途取消、并发忙及超时的动态覆盖仍待；未声称完整抵抗同用户恶意持续文件置换。隔离浏览器使用合成元数据与临时数据库，实际预览/证据展开/关闭，卡片数保持 0。正式个人来源、真实安装和最终保存流程另行验收，Issue #33 保持开放。
